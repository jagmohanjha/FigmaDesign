# Figma to Code

This project is based on a Figma design that I converted into a working webpage using HTML, CSS, and JavaScript.

The main goal was to recreate the given design as closely as possible and make the page interactive.

## Features

- Navigation bar with mobile menu
- Header section
- Projects section
- Recommendations section with carousel
- Contact form with basic validation
- Footer section
- Smooth scrolling and simple animations

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

While working on this project, I got hands-on practice with HTML, CSS, and JavaScript. I learned how to use Figma design properties such as spacing, fonts, colors, and layouts to recreate a webpage. I also practiced adding interactive elements using JavaScript.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
